# Modern Todo App

A clean, minimalist todo application inspired by Linear and Notion, built with Next.js 14, TypeScript, and Tailwind CSS.

## Features

- ✨ Modern, clean UI inspired by Linear and Notion
- 🌙 Dark mode support with system preference detection
- 📱 Fully responsive design
- ⚡ Smooth animations with Framer Motion
- 💾 Local storage persistence
- 🔍 Filter todos by all/active/completed
- ✏️ Inline editing with keyboard shortcuts
- 📊 Progress tracking with visual indicators
- 🎯 TypeScript for type safety
