Create a complete, production-ready Todo application with these specifications:

PROJECT: Modern Todo App with Next.js 14 App Router
TARGET: v0-todo-app-complete

DESIGN REQUIREMENTS:
- Modern, clean interface inspired by Linear and Notion
- Glass-morphism effects with backdrop-blur
- Smooth animations using Framer Motion
- Fully responsive (mobile-first design)
- Dark mode with system preference detection

COLOR PALETTE:
- Light mode:
  - Background: white/gray-50
  - Surface: white with subtle shadows
  - Primary: blue-600
  - Text: gray-900
- Dark mode:
  - Background: gray-900/black
  - Surface: gray-800 with borders
  - Primary: blue-500
  - Text: gray-100

CORE FEATURES:
1. Todo CRUD Operations
   - Add todos with Enter key (focus auto-returns to input)
   - Edit inline by clicking todo text (Escape to cancel)
   - Delete with slide gesture on mobile, hover button on desktop
   - Toggle complete with satisfying animation
   - Batch operations with shift+click selection

2. Advanced Filtering
   - Quick filters: All | Active | Completed
   - Search with debounced input
   - Priority levels: High (red) | Medium (yellow) | Low (green)
   - Due date filtering
   - Tags/categories with colors

3. Data Persistence
   - LocalStorage with optimistic updates
   - Export to JSON/CSV
   - Import from file
   - Sync indicator when saving

4. Keyboard Shortcuts
   - Cmd/Ctrl + K: Quick search
   - Cmd/Ctrl + N: New todo
   - Cmd/Ctrl + D: Toggle dark mode
   - ?: Show shortcuts overlay
   - Escape: Close modals/cancel edit

5. Rich Interactions
   - Drag & drop reordering with react-beautiful-dnd
   - Swipe actions on mobile
   - Context menus on right-click
   - Bulk actions toolbar
   - Undo/redo with toast notifications
